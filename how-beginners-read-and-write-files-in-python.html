How Beginners Read and Write Files in Python

Digitalskillguide · Programming · 23 November 2026 · 7 min read

Short answer: You learn how to read and write files in Python for beginners by opening a file with the open function and naming a mode. Python pulls text from the file into your program, and it sends text back in write mode.

Most beginners open a file with the write mode when they only want to read it, and that mode wipes the old text at once. They lose notes they spent hours writing, and they blame Python for the wrong mode.

You will read and write files with calm, and you will keep your notes safe. You will build small tools that save real work to files.

Open a File and Read What It Holds

Python opens a file with one short call, and the call tells Python which file to open and how to use it. You pass the file name and a mode letter, and Python hands you a file object that you can read from. You then read the text with a simple method, and the text arrives in your program as a plain string.

Use the Open Function With a Read Mode

You call open with the file name and the letter r, and the letter r tells Python that you only want to read. Python then gives you a file object, and you call read on it to pull the whole text into one string. You print that string to check the result, and the file text shows on your screen at once.

Read the Whole File or One Line at a Time

The read method pulls the whole file into one string, and that suits a short file that you want to search in one go. The readline method pulls a single line instead, and you call it again to move to the next line. The readlines method pulls every line into a list, and you loop through the list when you want to handle each line on its own.

Write New Text and Add to an Existing File

This guide shows how to read and write files in Python for beginners through small steps, and writing is the second half of the skill. You open a file with the letter w when you want fresh text, and you open it with the letter a when you want to add to old text. You call write with the text you want to save, and Python places it in the file for you.

Create a File With Write Mode

You open a file with the letter w, and Python creates the file when it does not exist yet. You call write with your text, and Python saves the text into the new file at once. You close the file after the write, and the text stays safe on your disk for the next time you need it.

Add New Lines With Append Mode

The letter a opens a file in append mode, and Python adds your new text after the old text without touching it. You use append for a log file or a notes file that grows a little each day, and the old lines stay right where they were. A shopkeeper in Multan adds the total sales of each day to one file with append mode, and the file now holds a full month of totals in one place.

Use With Open So Files Close on Their Own

You learn how to read and write files in Python for beginners best when you use the with statement, because it closes the file for you. You write with open and a short block of code under it, and Python closes the file the moment the block ends. You never forget a close again, and your files never stay open by mistake.

See Why With Open Beats a Manual Close

A manual close needs a close call after every open, and one missed call leaves the file open in the background. The with statement removes that risk, because Python runs the close for you even when an error hits the block. You write less code, and you gain a file that always ends in a clean state.

Handle a Missing File Without a Crash

A program that opens a file which does not exist will crash, and the crash shows a FileNotFoundError on your screen. You wrap the open call in a try block, and you catch the error with a short message that tells the user what went wrong. A student in Lahore built a notes app this way, and it now shows a kind note when the notes file is missing instead of a crash.

Practise With a Small Project That Uses Real Files

A small project turns the three modes into a skill you keep, because real files give you real feedback. You build a notes file that you can read, add to, and grow over a week. You then read the file back each morning, and you watch your own words come back from the disk.

Build a Simple Notes File You Can Grow

You write a short script that asks for one note, and it appends the note to a file named notes with the append mode. You run the script each evening, and the file grows by one line each day. Save and Read Back a Short List

You save a short list of tasks to a file with write mode, and you read the list back the next morning with read mode. The round trip proves that your code saves and loads real data, and the proof builds your trust in the skill. Frequently Asked Questions

What does the open function do in Python?

The open function opens a file and returns a file object that your code can read from or write to. You pass the file name and a mode letter, and Python prepares the file for the mode you chose.

Which mode reads a file in Python?

The letter r opens a file in read mode, and you call read or readline on the file object to pull the text. You use read mode when you only want to look at the text and change nothing.

What is the difference between write mode and append mode?

Write mode clears the old text and starts fresh, while append mode keeps the old text and adds new text at the end. You use write mode for a fresh file, and you use append mode for a log or a notes file that grows.

How do I learn file handling in Python as a beginner?

You learn how to read and write files in Python for beginners by writing tiny scripts that save and load real text. You start with read mode and write mode, and you add the with statement once those two feel easy.

What does the with statement do when I open a file?

The with statement opens the file and closes it on its own when the block ends. You write less code, and the file never stays open by mistake.

What happens when I open a file that does not exist?

Python shows a FileNotFoundError when you open a missing file in read mode, and the program stops at that line. You catch the error with a try block, and you show a kind message instead of a crash.

Can I read a file line by line in Python?

You can read a file line by line with readline, and you can loop through the file object to visit each line in turn. You use this route for a long file, because it keeps only one line in memory at a time.

How do I practise file handling every day?

You pick one small file task each day, such as saving a notes file or reading a list back. You run the script, check the file on your disk, and fix any surprise at once. The daily habit turns file handling into a skill you trust.
