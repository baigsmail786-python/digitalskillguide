Read the Whole File or One Line at a Time

The read method pulls the whole file into one string, and that suits a short file that you want to search in one go. The letter a opens a file in append mode, and Python adds your new text after the old text without touching it. You write with open and a short block of code under it, and Python closes the file the moment the block ends. You never forget a close again, and your files never stay open by mistake.

A manual close needs a close call after every open, and one missed call leaves the file open in the background. The with statement removes that risk, because Python runs the close for you even when an error hits the block. You write less code, and you gain a file that always ends in a clean state.
