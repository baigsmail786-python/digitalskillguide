Frequently Asked Questions

What is a for loop in Python?

A for loop repeats a job once for each item in a list, a string, or a range of numbers. You write the word for, then a name for each item, then the word in, then the collection. You use it when you know the items in advance and you want the same job done for each one.

What is a while loop in Python?

A while loop repeats a job while a test stays true, and it checks the test before each pass. You use it when you do not know how many passes you need, such as waiting for a user to type quit. You always change the test value inside the loop, or the loop runs forever.

How do I stop an infinite loop in Python?

You stop a running loop in most editors by pressing Control and C together, and the program halts at once. You prevent the next one by checking that the test value changes inside the loop. You add break as a second guard, so the loop has a clear way out.

What does break do in a Python loop?

Break ends a loop at once, and Python jumps to the first line after the loop. You use it when a search finds its target, when a user types quit, or when a limit is reached. You place break inside an if line, so it runs only when the condition is met.

What is the difference between break and continue in Python?

Break ends the whole loop, and continue skips the rest of the current pass and starts the next one. You use break when the job is done, and you use continue when one item needs skipping but the loop must go on. You keep both close to the test that triggers them, so the code stays clear.

What is a nested loop in Python?

A nested loop sits inside another loop, and the inner loop runs fully for each single pass of the outer loop. You use nested loops for tables, grids, and pairs, such as rows and columns. You indent the inner loop one level deeper, and you keep both loops short so the code stays easy to follow.

How do I use range in a Python for loop?

You use range to count, and you write range with a stop number to count from zero upward. You add a start number when you want to begin elsewhere, and you add a step when you want to skip numbers. You remember that range stops one short of the stop number, so range with three and eight gives you three through seven.

How do I learn to use Python loops as a beginner?

You learn how to use Python loops for beginners by writing one small loop a day on a real task, such as a list, a menu, or a game. You start with for loops, and you add while loops and break once for loops feel easy. You then build the number guessing game, and the project turns the separate moves into one skill.
